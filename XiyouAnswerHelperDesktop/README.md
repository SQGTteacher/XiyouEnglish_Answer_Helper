# 西柚答案助手 · 使用说明

一个**始终置顶**的小窗口，两种方式拿答案：

1. **在线模式（新增）**：直接输入西柚账号密码，登录后在窗口里选作业，自动取本次试题答案；
2. **本地模式（原有）**：自动监控西柚英语客户端的存储目录，你在客户端点「开始答题」，答案立刻出现。

> 文件与路径全部为英文，程序内部界面保持中文。

---

## 一、怎么启动

双击 `XiyouAnswerHelper.exe`，或运行 `Start-XiyouAnswerHelper.bat`。

> 说明：某些开发环境的命令行里会带 `ELECTRON_RUN_AS_NODE=1`，这会让 Electron
> 退化成纯 Node 而打不开界面。`.bat` 会先清掉它。从桌面/开始菜单快捷方式启动不受影响。

---

## 二、在线模式（账号登录取答案）

1. 点工具栏的 **账号** 按钮；
2. 输入西柚英语账号和密码，点「登录」（勾选「记住账号密码」会加密保存在本机，下次自动带出）；
3. 登录后弹出作业列表，点一份作业即可取到答案；
   - 作业按作业本分组时，先点作业本，再点里面的题目；
   - 取答案成功后窗口自动关闭浮层并显示答案。
4. 需要换账号时，再次点「账号」→ 在作业列表浮层里点「退出登录」。

**在线模式的特点**

- 请求与电脑端网页完全一致：电脑版 UA、`device=web-pc`、同样的签名；
- 走 `/paper/module/detail`（也就是客户端「开始答题」时拉的整份试卷，答案内嵌其中）；
- 只用账号密码，不依赖客户端是否在运行，也不需要开调试端口。

---

## 三、本地模式（监控客户端）

1. 打开「西柚英语个人版」，正常登录。
2. 打开助手窗口（会自动置顶在右上角）。
3. 在客户端里：**班级 → 作业 → 去完成 → 开始答题**。
4. 助手窗口会自动跳出这份试卷的**全部答案**，无需任何手动操作。

> 客户端不需要特殊启动参数，助手读的是磁盘上的 LevelDB 文件，对客户端零侵入。

---

## 四、界面说明

| 位置 | 功能 |
|---|---|
| 顶部下拉框 | 切换历史试题（本地捕获与在线获取都会保留最近 60 份） |
| `账号` | 打开账号登录 / 作业列表（在线取答案） |
| `复制全部` | 按下面固定格式复制整份答案 |
| `详细` | 开关详细答案：题干、全部参考答案、关键词、踩分点、听力原文、选择题正确项 |
| `A-` / `A+` | 调整字号 |
| 右侧滑条 | 窗口透明度 |
| `⟳` | 立刻重新扫描一次 |
| `⇧` | 置顶开关（默认开） |
| `–` / `✕` | 最小化 / 关闭 |
| `启动客户端` | 帮你以调试端口重启客户端（可开启亚秒级实时通道，可选） |
| `打开目录` | 在资源管理器中打开被监控的目录 |
| `穿透` | 鼠标穿透：开启后鼠标点击会穿过助手窗口落到客户端上 |

**快捷键**

* `Ctrl + Alt + X` — 切换鼠标穿透
* `Ctrl + Alt + Z` — 显示 / 隐藏助手窗口

### 关于「穿透」

点「穿透」后，助手窗口会整体忽略鼠标，你可以直接点到下面的客户端。
此时窗口右上角会浮出一个**橙色的「恢复点击」小按钮**——它独立于主窗口、
永远不会穿透，**点它一下即可恢复**。按钮上的文字也写了快捷键。

想关闭穿透有三种方式，任意一种都行：

1. 点橙色的「恢复点击」按钮；
2. 按 `Ctrl + Alt + X`；
3. 按 `Ctrl + Alt + Z` 先把窗口藏起来，再按一次显示。

**小技巧**

* 单击某一条答案 = 复制该条。
* 打开「详细」可以看听力原文、朗读文本、关键词、踩分点。
* 选择题会把**正确选项**高亮成绿色并打 ✔，你自己选的错误项打 ✘。

## 五、答案输出格式

默认（未勾选「详细」）严格按下面的格式，每个题目只取答案文件里的**第一项**：

```
（试题标题）

一、模仿朗读
<朗读原文 / 答案>

二、角色扮演
三问：
1. <第一项答案>
2. <第一项答案>
3. <第一项答案>
五答：
1. <第一项答案>
2. <第一项答案>
3. <第一项答案>
4. <第一项答案>
5. <第一项答案>

三、故事复述
<第一篇范文>
```

勾选「详细」后，每题追加：题干、全部参考答案、关键词、得分要点、听力/朗读原文、选择题正确项。

## 六、答案是从哪来的

### 6.1 在线模式

复刻学生端网页 4.8.6 的请求：

| 步骤 | 接口 |
|---|---|
| 登录 | `POST https://app.xiyouyingyu.com/user/login/account`（表单：`loginAccount` + 明文 `password`） |
| 作业列表 | `POST /homework/findBagListV2`（JSON：`userId` / `clazzId` / `homeworkStatus`） |
| 作业本明细 | `POST /homework/findListByBagIdV2` |
| 取试卷（含答案） | `POST /paper/module/detail`（表单：`groupId`） |

签名与网页端一致：

```
sign = md5( 按 key 升序拼接的 "k=v&k=v" + "_Sts100#@" )
公共参数：appVersion / belong / device=web-pc / osVersion / release / brand / timestamp / sessionId / userId
请求头：release / device / sign / udid
```

### 6.2 本地模式

```
%APPDATA%\web-desktop\Session Storage\
   000004.log / 000005.ldb      ← LevelDB，键 map-1-vuex
                                   值是 UTF-16LE 的 JSON
                                   → params.paperGroupList 里就是整份试卷 + 全部答案
```

助手用自己实现的纯 JS LevelDB 解析器读取（支持 WAL、SSTable、Snappy 解块），
**只读、不写入、不上传**，不会影响客户端本身。

详细格式见同目录下的 `REVERSE_ENGINEERING.md`。

### 6.3 本机数据位置

```
%APPDATA%\XiyouAnswerHelper\papers.json      捕获 / 获取历史
%APPDATA%\XiyouAnswerHelper\account.json     账号（密码用 Windows DPAPI 加密）
```

删掉这两个文件即可清空历史与账号。

## 七、常见问题

**Q：在线模式提示「用户名或密码错误」？**
A：确认账号密码与电脑客户端登录的一致；若手机号绑定多个学生账号，请用学生账号本身登录。

**Q：在线模式作业列表是空的？**
A：只列出当前待完成的作业；已完成的不会显示。可以让老师重新发布，或换个时间再点「刷新」。

**Q：窗口显示「还没有捕获到试题」？**
A：本地模式需要先在客户端点过「开始答题」；也可以直接点「账号」在线取答案。

**Q：状态栏显示「未找到客户端数据目录」？**
A：说明西柚英语客户端从没运行过，或没登录过。先打开客户端登录一次；或忽略，直接用在线模式。

**Q：为什么本地模式有时候要等几秒才出现答案？**
A：客户端把答案写进 sessionStorage 后，Chromium 会延迟若干秒才提交到磁盘。
助手每 1.2 秒扫一次，通常 1–5 秒内出现。
点「启动客户端」按钮让客户端带调试端口启动，可以变成亚秒级实时。

**Q：会不会影响我正常答题 / 会不会被老师发现？**
A：助手只读取本机磁盘上已经存在的数据，或按网页端同样的方式请求试卷，不修改服务器数据，
也不代替你作答。是否使用请自行判断并遵守学校规定。

**Q：答案会一直留着吗？**
A：会。本地捕获或在线获取后都会存进 `papers.json`，即使关掉客户端、清空客户端缓存，历史记录仍然在。

**Q：开了穿透之后点不到窗口了怎么办？**
A：不会。开启穿透的瞬间右上角会出现橙色的「恢复点击」小按钮（它不穿透），
点一下就好；也可以直接按 `Ctrl + Alt + X`。

## 八、目录结构

```
XiyouAnswerHelperDesktop\
├─ Start-XiyouAnswerHelper.bat      启动脚本（会清理 ELECTRON_RUN_AS_NODE）
├─ XiyouAnswerHelper.exe            Electron 22 运行时（改名）
├─ *.dll / *.pak / locales\         运行时依赖
├─ README.md                        本说明
├─ REVERSE_ENGINEERING.md           逆向分析报告（存储位置 / 文件格式）
├─ build\icon.ico                   图标源文件
└─ resources\app\                   程序本体（纯 JS，可直接阅读修改）
    ├─ main.js                      主进程：监控、在线接口、窗口、热键、IPC
    ├─ preload.js                   安全桥（contextBridge）
    ├─ src\
    │   ├─ xiyou-api.js             在线接口（登录 / 作业 / 试卷 / 签名）
    │   ├─ leveldb-read.js          纯 JS LevelDB 读取器（WAL + SSTable + Snappy）
    │   ├─ storage-source.js        定位客户端目录、取出最新含答案的版本
    │   ├─ paper-parser.js          试卷 / 答案解析器
    │   ├─ cdp-source.js            可选的 CDP 实时通道
    │   ├─ ws.js                    极简 RFC6455 WebSocket 客户端
    │   └─ vendor\snappy.js         内置 Snappy 解压（无任何 npm 依赖）
    └─ renderer\                    界面（HTML/CSS/JS）
        ├─ index.html / app.js / style.css    主界面（含账号登录浮层）
        ├─ answer-format.js          指定格式排版（简洁 / 详细）
        └─ restore.html / restore.js          「恢复点击」浮窗（永不穿透）
```

> `resources\app.asar.orig` 是改动前的旧打包备份，程序已改为直接加载 `resources\app` 目录，
> 修改 JS 后重启窗口即可生效。
